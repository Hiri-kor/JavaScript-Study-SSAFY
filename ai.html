① 프롬프트 복사

아래 프롬프트의 [출제 조건]과 [학습 범위]를 채워 AI에게 보내세요. 주제 페이지 본문을 복사해 [학습 범위]에 붙여넣으면 교안 범위 안에서만 출제됩니다.

② 문제 가져오기

AI가 준 JSON 배열을 그대로 붙여넣으세요. 형식을 검사한 뒤 이 브라우저에 저장합니다.

    배포 사이트에도 문제를 올리려면?
    1. "배포용 JSON 복사"를 누르고, ai_problems/ 폴더에 이름.json 파일로 저장합니다.
    2. 저장소 루트에서 python tools/import_ai_problems.py를 실행하면 data/ai-questions.js가 다시 만들어집니다.
    3. 커밋 후 push 하면 GitHub Pages에서도 보입니다. 그 뒤엔 "브라우저에 저장된 AI 문제 지우기"로 중복을 정리하세요.
    4. md 형식(객관식 50제처럼)으로 받은 문제는 ai_problems/에 넣고 스크립트 상단 FILES에 주제 배치 규칙을 추가하세요.
