## [1~5] 데이터 타입 (원시 자료형과 참조 자료형)

**1. JavaScript의 데이터 타입은 크게 원시 자료형(Primitive type)과 참조 자료형(Reference type)으로 나뉩니다. 변수 간 할당 시 원시 자료형은 '무엇'이 복사되고, 참조 자료형은 '무엇'이 복사되는지 각각 쓰시오.**

**2. 다음 코드를 실행했을 때 콘솔에 출력될 결과를 순서대로 쓰시오.**
```js
let b = 10
let c = b
c = 20

const obj1 = { name: 'Alice', age: 30 }
const obj2 = obj1
obj2.age = 40

console.log(b, c)
console.log(obj1.age, obj2.age)
```

**3. 백틱(`` ` ``)을 사용하여 문자열을 정의하며, 여러 줄에 걸쳐 문자열을 작성하거나 `${expression}` 형태로 변수를 문자열 안에 바로 연결할 수 있는 ES6+의 문자열 작성 방식을 무엇이라고 하는지 쓰시오.**

**4. JavaScript에서 '값이 없음'을 나타내는 두 가지 원시 자료형 중, (1) 개발자가 의도적으로 값이 없음을 나타낼 때 사용하는 것과 (2) 시스템이나 엔진이 값이 할당되지 않았음을 나타낼 때 사용하는 것을 각각 구분하여 쓰시오.**

**5. 다음 세 줄의 코드를 실행했을 때 콘솔에 출력되는 결과를 순서대로 쓰시오.**
```js
console.log(typeof null)
console.log(typeof undefined)
console.log(typeof NaN)
```

## [6~9] 연산자 및 조건문

**6. 다음 코드를 실행했을 때 콘솔에 출력되는 `x`, `y`, `m`, `n`의 값을 순서대로 쓰시오.**
```js
let x = 5
const y = x++

let m = 5
const n = --m

console.log(x, y, m, n)
```

**7. 동등 연산자(`==`)와 일치 연산자(`===`)의 가장 핵심적인 차이점을 '타입 변환'이라는 키워드를 포함하여 서술하시오.**

**8. 논리 연산자의 단축 평가(Short-circuit evaluation)가 적용된 다음 코드의 출력 결과를 순서대로 쓰시오.**
```js
console.log(1 && 0)
console.log(4 && 7)
console.log(0 || 1)
console.log(4 || 7)
```

**9. 다음 `if...else` 조건문을 동일한 동작을 하는 '삼항 연산자' 표현식 한 줄로 변환하여 빈칸을 채우시오.**
```js
const age = 20
let message
if (age >= 18) {
  message = '성인'
} else {
  message = '미성년자'
}

// 삼항 연산자로 변환:
const message = _______________________________________
```

## [10~14] 반복문

**10. 객체의 열거 가능한 속성(property)의 '키(key)'를 순회할 때 사용하는 반복문과, 배열 등 반복 가능한(iterable) 객체의 '값(value)'을 순회할 때 사용하는 반복문의 이름을 각각 쓰시오.**

**11. 다음 두 반복문을 실행했을 때 콘솔에 출력되는 결과를 각각 쓰시오.**
```js
const arr = ['a', 'b', 'c']

// (1) 첫 번째 반복문
for (const i in arr) {
  console.log(i)
}

// (2) 두 번째 반복문
for (const i of arr) {
  console.log(i)
}
```

**12. 일반 객체 `const capitals = { korea: '서울', japan: '도쿄' }`에 대해 `for (const capital of capitals)`를 실행하면 어떤 에러가 발생하는지 에러의 종류(이름)와 그 이유를 간단히 쓰시오.**

**13. 배열을 순회할 때 `for...in` 반복문을 사용하지 않고 일반 `for` 문이나 `for...of` 문을 사용할 것을 권장하는 이유를 2가지 이상 서술하시오.**

**14. 일반 `for` 문(`for (let i = 0; i < 5; i++)`)에서는 제어 변수 선언에 `const`를 사용하면 에러가 발생하지만, `for...in`이나 `for...of` 반복문에서는 `const`를 사용해도 에러가 발생하지 않는 이유를 서술하시오.**

## [15~20] 함수 (정의, 매개변수, 전개 구문, 화살표 함수)

**15. 자바스크립트 엔진이 코드 실행 전 변수와 함수 선언을 먼저 등록해서, 선언이 스코프 최상단으로 끌어올려진 것처럼 보이는 현상을 무엇이라고 하는지 쓰시오.**

**16. 함수 선언식과 달리, `const`나 `let`을 사용한 함수 표현식을 선언 전에 호출하면 `ReferenceError`가 발생합니다. 변수가 호이스팅되었음에도 선언한 줄에 도달하기 전까지 접근할 수 없는 이 구간을 무엇이라고 부르는지 쓰시오. (약어 또는 전체 명칭)**

**17. 함수 정의 시 정해지지 않은 개수의 인자들을 하나의 '배열'로 모아서 받기 위해 사용하는 매개변수 문법의 명칭을 쓰고, 아래 코드의 출력 결과를 쓰시오.**
```js
const myFunc = function (a, b, ...rest) {
  return [a, b, rest]
}
console.log(myFunc(10, 20, 30, 40))
console.log(myFunc(10, 20))
```

**18. 다음 두 함수를 호출했을 때 콘솔에 출력되는 결과를 각각 쓰시오.**
```js
const threeArgs = function (p1, p2, p3) {
  return [p1, p2, p3]
}
console.log(threeArgs(1, 2))

const twoArgs = function (p1, p2) {
  return [p1, p2]
}
console.log(twoArgs(1, 2, 3, 4))
```

**19. 다음 함수 표현식을 인자의 소괄호 `()`, 본문의 중괄호 `{}`, 그리고 `return` 키워드를 모두 생략한 가장 간결한 형태의 '화살표 함수(Arrow function)'로 다시 작성하시오.**
```js
const greet = function (name) {
  return `hello, ${name}`
}
```

**20. 화살표 함수에서 `return` 키워드와 중괄호를 생략하고 객체 `{ key: 'value' }`를 즉시 반환하려고 할 때, 아래와 같이 작성하면 `undefined`가 반환됩니다. 올바르게 객체를 반환하도록 코드를 수정하시오.**
```js
// 잘못된 코드
const returnObject = () => { key: 'value' }
```

## 정답 및 해설

| 문항 | 정답 | 해설 |
|:---:|---|---|
| **1** | • 원시 자료형: **값(value)**<br>• 참조 자료형: **메모리의 주소(address)** | 원시 자료형은 값 자체가 변수에 저장되어 할당 시 값이 복사되고, 참조 자료형은 데이터가 저장된 메모리의 주소가 복사됩니다. |
| **2** | • 첫째 줄: `10 20`<br>• 둘째 줄: `40 40` | 원시 자료형(`b`, `c`)은 값이 복사되어 서로 영향을 주지 않지만, 참조 자료형(`obj1`, `obj2`)은 주소를 공유하므로 `obj2.age`를 바꾸면 `obj1.age`도 함께 변경됩니다. |
| **3** | **템플릿 리터럴 (Template literals)** | 템플릿 리터럴은 내장된 표현식(`${}`)과 멀티라인 문자열을 지원하는 향상된 문자열 작성 방식입니다. |
| **4** | (1) **`null`**<br>(2) **`undefined`** | `null`은 프로그래머가 의도적으로 '값이 없음'을 할당할 때 쓰고, `undefined`는 변수를 선언만 하고 값을 할당하지 않았을 때 시스템이 자동으로 부여합니다. |
| **5** | • `'object'`<br>• `'undefined'`<br>• `'number'` | `typeof null`은 초기 JS의 버그로 인해 `'object'`를 반환하며, `NaN`(Not a Number)의 타입은 역설적이게도 `'number'`입니다. |
| **6** | `6, 5, 4, 4` | `y = x++`는 증가 전의 값 `5`를 `y`에 할당한 후 `x`를 `6`으로 만듭니다. `n = --m`은 `m`을 먼저 `4`로 감소시킨 후 그 값 `4`를 `n`에 할당합니다. |
| **7** | 동등 연산자(`==`)는 **암묵적 타입 변환**을 통해 타입을 일치시킨 후 값을 비교하지만, 일치 연산자(`===`)는 **암묵적 타입 변환 없이** 값과 타입이 모두 같은지 엄격하게 비교한다. | 예측하지 못한 암묵적 타입 변환으로 인한 버그를 막기 위해 특별한 경우를 제외하고는 일치 연산자(`===`) 사용이 권장됩니다. |
| **8** | `0`, `7`, `1`, `4` | `&&`는 좌항이 참이면 우항을 반환하고 거짓이면 좌항을 즉시 반환합니다. `||`는 좌항이 참이면 좌항을 즉시 반환하고 거짓이면 우항을 반환합니다. |
| **9** | `(age >= 18) ? '성인' : '미성년자'`<br>*(소괄호 생략 가능)* | 삼항 연산자는 `조건식 ? 참일_때_표현식 : 거짓일_때_표현식`의 구조로 작성합니다. |
| **10** | • 키(key) 순회: **`for...in`**<br>• 값(value) 순회: **`for...of`** | `for...in`은 객체의 열거 가능한 속성 키를 순회하고, `for...of`는 반복 가능한(iterable) 객체의 요소를 순회합니다. |
| **11** | (1) `'0'`, `'1'`, `'2'` (문자열 인덱스)<br>(2) `'a'`, `'b'`, `'c'` (배열의 요소 값) | 배열에 `for...in`을 쓰면 인덱스(속성 키)가 문자열로 출력되며, `for...of`를 쓰면 실제 요소의 값이 출력됩니다. |
| **12** | • 에러: **`TypeError`** (`capitals is not iterable`)<br>• 이유: 일반 객체는 **반복 가능한(iterable) 객체가 아니기 때문**이다. | `for...of`는 배열, 문자열 등 iterable 프로토콜을 구현한 객체에만 사용할 수 있습니다. |
| **13** | 1) 배열의 값이 아닌 **문자열 인덱스**를 반환하기 때문<br>2) 인덱스 반환 **순서를 보장하지 않기** 때문<br>3) 배열의 **프로토타입 체인 상에 추가된 속성**이나 정수가 아닌 속성까지 순회할 수 있기 때문 | 위 3가지 이유 중 2가지 이상을 작성하면 정답입니다. 배열 순회 시에는 `for` 문이나 `for...of`를 사용해야 안전합니다. |
| **14** | 일반 `for` 문은 기존 변수를 계속 **재할당**(`i++`)하며 사용하지만, `for...in`과 `for...of`는 재할당이 아니라 **매 반복마다 새로운 변수에 속성이나 값이 지정(바인딩)**되기 때문이다. | 단, `const`의 특징에 따라 반복문 코드 블록 `{}` 내부에서 해당 변수의 값을 직접 수정(재할당)할 수는 없습니다. |
| **15** | **호이스팅 (Hoisting)** | 함수 선언식은 함수 전체가 호이스팅되어 선언 전에도 호출할 수 있습니다. |
| **16** | **TDZ (Temporal Dead Zone, 일시적 사각지대)** | `let`과 `const`로 선언된 변수는 호이스팅되지만 초기화 줄에 도달하기 전까지 TDZ에 머물러 접근 시 `ReferenceError`를 발생시킵니다. |
| **17** | • 명칭: **나머지 매개변수 (Rest parameter)**<br>• 첫째 줄 출력: `[10, 20, [30, 40]]`<br>• 둘째 줄 출력: `[10, 20, []]` | `...rest`는 남은 인자들을 배열로 묶어주며, 전달된 나머지 인자가 없을 경우 빈 배열(`[]`)이 할당됩니다. |
| **18** | • 첫째 줄: `[1, 2, undefined]`<br>• 둘째 줄: `[1, 2]` | 매개변수보다 인자가 적으면 누락된 자리에 `undefined`가 할당되고, 매개변수보다 인자가 많으면 초과된 인자는 무시됩니다. |
| **19** | ``const greet = name => `hello, ${name}` `` | 매개변수가 1개일 때 `()` 생략 가능하며, 본문이 `return`을 포함한 표현식 1줄일 때 `{}`와 `return`을 함께 생략할 수 있습니다. |
| **20** | `const returnObject = () => ({ key: 'value' })` | 화살표 함수에서 중괄호 `{}`는 함수 본문 블록으로 인식되므로, 객체를 암시적으로 반환하려면 소괄호 `()`로 객체를 감싸야 합니다. |
