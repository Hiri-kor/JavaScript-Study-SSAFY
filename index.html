📚 주제별 학습

🧭 추천 학습 순서

  1. 주제별 학습으로 개념을 읽고, 코드 블록의 ⌨ 따라치기로 예제를 직접 쳐 봅니다.
  2. 각 주제 끝의 확인 문제를 풉니다. 정답과 해설은 채점한 뒤에만 보여요.
  3. AI 문제로 객관식·주관식·빈칸·서술형 문제를 더 풀어 봅니다.
  4. 시험 전날엔 시험 직전 문제를 모의고사 모드로 풀고 오답 노트를 정리합니다.
  5. 시험 직전엔 시험 직전 개념만 훑어봅니다.

🎯 유형별 대비 포인트

객관식

  • 비슷한 짝을 구분: querySelector/All, map/forEach, target/currentTarget
  • "아닌 것", "틀린 것"을 묻는 문제에 주의

주관식

  • 메서드 이름은 철자·대소문자까지 정확히 (addEventListener, textContent)
  • 코드 출력값 예측: ==/===, 단축 평가, 호이스팅

서술형

  • 정의 → 특징/이유 → 예시 순서로 쓰기
  • 시험 직전 개념의 "서술형 한 줄 정의"를 외워 두기
